# Project 18: Event Management System (CELEBRATIO)

Experiential event management and live tiered ticketing platform built with React, Vite, TailwindCSS, and Zustand.

## Features
- **Celebratory Pastel-Gradient UI**: Playful script typography (`Pacifico`), vibrant pastel gradient palette (`#fdf2f8`, `#f0abfc`, `#818cf8`, `#38bdf8`), confetti accents, and hero media banner.
- **Tiered Ticket Sales & Reservations**: General Admission, VIP Luminary Pass, and Artist Circle tiers with live inventory limits and Stripe test-mode checkout simulation.
- **Interactive Stage Schedule**: Multi-track agenda timeline with presenter attribution and session timing.
- **QR Code Check-In Optical Scanner**: Simulated live QR scanner with instant pass validation and attendee status updates.
- **Attendee Registry Vault**: Real-time attendee listing with single-use cryptographic QR token hashes and email reminder triggers.
- **Event Turnout & Revenue Analytics**: Gross ticketing revenue, occupancy percentage, guest review scores, and check-in velocity.

## Getting Started
```bash
npm install
npm run dev
```
